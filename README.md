## 🚀 주요 기능 및 화면 구성

### 1. 헤더 (Header) & 실시간 정각 타이머
- **정각 카운트다운 타이머**: `[최근 업데이트: HH:00 / 다음 업데이트까지 MM:SS]` 형태의 초 단위 실시간 카운트다운 타이머를 헤더에 배치하여, 사이트의 핵심 정체성인 '매시 정각 큐레이션'의 신뢰도를 시각화.
- **지금 갱신 버튼 (`↻`)**: 정각이 아니더라도 사용자가 즉시 데이터를 최신화할 수 있는 원클릭 수동 갱신 기능.
- **시니어/중장년 맞춤 가독성 도구**: 본문 글자 크기를 3단계(`가` / `가+` / `가++`)로 즉시 확대/축소 가능.
- **다크/라이트 모드**: 야간에도 눈이 편안한 테마 전환 지원 (설정 자동 저장).

### 2. 메인 콘텐츠 3단 그리드 레이아웃 (정보 밀도 극대화)
정보를 빠르고 효율적으로 소비하는 타겟층의 특성에 맞춰 3단 레이아웃을 채택:

1. **[좌측] 핫라인 뉴스 (메인 노출 뉴스 큐레이션)**
   - **광고 배제 알고리즘**: 상업성 낚시 기사, 광고, 이벤트성 기사를 100% 필터링.
   - **TOP 헤드라인 (1건)**: 현재 시간 기준 가장 검색량이 높은 주요 이슈를 고화질 썸네일과 굵은 제목, 3줄 핵심 요약문으로 배치.
   - **스트레이트 뉴스 리스트**: 언론사 태그 및 등록 시간과 함께 텍스트 위주로 깔끔하게 리스트업 (클릭 시 언론사 원문 새 창 연결).

2. **[중앙] 실시간 유튜브 트렌드 (조회수 1,000 이상 하이라이트)**
   - 시각적 주목도가 가장 높은 중앙에 영상 썸네일 갤러리/피드 배치.
   - **조회수 1,000회 이상 검증된 영상만 엄선**: 신뢰도 높은 경제/시사/국방 채널의 영상을 큐레이션.
   - 썸네일, 제목, 채널명, 실시간 조회수를 **직관적인 붉은색 뱃지**(`조회수 14.8만회`)로 강조.

3. **[우측] 오픈 커뮤니티 실시간 베스트 (무가입 기반)**
   - **무가입 접근성 극대화**: 디시인사이드(실시간 베스트), 에펨코리아(포텐) 등 회원가입 없이 누구나 볼 수 있는 오픈 커뮤니티 인기글 취합.
   - 출처 커뮤니티의 **파비콘 아이콘**과 **실시간 조회수/추천수 뱃지** 표기.

---

### 3. 우측 사이드바: 시간대별 급상승 검색어 (1위~10위)
- 보수 타겟층이 실시간으로 가장 많이 검색하는 핵심 키워드 1~10위 랭킹 노출.
- 순위 변동 아이콘(`▲ 2`, `▼ 1`, `NEW`, `-`) 및 검색량 표기.
- **원클릭 스마트 필터링**: 특정 키워드를 클릭하면 화면 내 뉴스, 유튜브, 커뮤니티 콘텐츠가 해당 주제로 즉각 필터링됩니다.

---

### 4. 추가 기획 코너 4선

1. **🛡️ 바른 팩트체크 (Fact Check)**
   - 가짜뉴스와 왜곡된 주장에 대한 피로도를 해소하기 위한 팩트 기반 검증 코너.
   - **"주장 - 팩트 - 근거 데이터"**의 3단 카드 구조로 정부 통계, OECD 보고서, IEA 단가 등 객관적 수치 제시.

2. **✒️ 원포인트 오피니언 (Opinion Leaders)**
   - 단순 속보를 넘어 자유시장경제, 국가안보, 법치 가치를 대변하는 지식인·학자·전문가의 사설/칼럼 엄선.
   - 아침/저녁 하루 2회 정기 큐레이션으로 사이트의 지적 깊이와 무게감 확보.

3. **🗳️ 비로그인 실시간 여론조사 (O/X 퀵 투표)**
   - 회원가입 없이 IP 및 브라우저 쿠키/스토리지 기반으로 1인 1투표 중복 방지.
   - "오늘의 핫이슈: OOO 정책, 찬성하십니까?" 단일 질문에 '찬성/반대' 클릭 시 실시간 집계 퍼센트(%) 그래프 즉각 시각화.

4. **📊 주간 키워드 데이터 리포트 (아카이브)**
   - 매주 지난 한 주간 바른결에서 가장 많이 노출되고 클릭된 키워드 TOP 10 및 주간 핵심 브리핑 모달 아카이브.

## 🌐 깃허브(GitHub) 업로드 및 전 세계 무료 웹사이트 배포

GitHub에 올리시면 **GitHub Pages 무료 웹 호스팅**을 통해, 컴퓨터를 꺼두어도 **전 세계 누구나 스마트폰/PC에서 접속할 수 있는 나만의 웹사이트 주소**가 생성됩니다!

### 🌟 방법 1: 원클릭 업로더 (Git 프로그램 설치 불필요!)
1. 최상위 폴더의 **`upload_bareungyeol_to_github.bat`** 파일을 더블 클릭합니다.
2. 안내에 따라 GitHub Personal Access Token을 입력하시면, 자동으로 저장소 생성부터 소스코드 푸시, GitHub Pages 활성화까지 100% 자동 완료됩니다.
3. 배포 완료 후 즉시 **`https://<내아이디>.github.io/bareungyeol/`** 주소로 접속하실 수 있습니다.

### 🌐 방법 2: GitHub 웹사이트에서 마우스로 직접 올리기
1. [GitHub.com](https://github.com)에 로그인 후 새 저장소(`bareungyeol`, Public)를 생성합니다.
2. `uploading an existing file`을 눌러 `bareungyeol` 폴더 안의 파일들을 마우스로 드래그하여 올리고 `Commit changes`를 누릅니다.
3. 저장소의 **`Settings` -> `Pages`** 메뉴에서 Branch를 **`main`** / **`/ (root)`** 로 설정하고 **`Save`**를 누르면 끝!

## 💻 컴퓨터 로컬 1초 실행 방법

컴퓨터에서 자체 백엔드 서버로 바로 실행하시려면:
1. 폴더 안에 있는 **`run_bareungyeol.bat`** 파일을 마우스로 **더블 클릭**합니다.
2. 검은색 창이 뜨며 서버가 켜지고, **기본 인터넷 브라우저(`http://localhost:8080`)가 자동으로 열립니다.**
3. 상단 헤더의 `📱 휴대폰 연결` 버튼을 누르면 실시간 스마트폰 접속 링크 및 QR코드가 나타납니다.
